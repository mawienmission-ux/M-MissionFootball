Enter previous league table totals

Enter each club's current totals from the real South Sudan league table. These values are used as the starting point; any finished match results you add afterward will be added on top. Do not also enter those same past matches as results, or they will count twice.

Manage clubs

To add a club, leave the selector on “Add a new club,” enter its details, and save. To replace an old club, select it, remove it, then add the replacement.
